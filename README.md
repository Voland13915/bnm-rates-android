# Курсы НБМ — Android (Kotlin)

Лабораторная работа №4, вариант Б: конвертер валют по официальному курсу
Национального банка Молдовы, заново написанный на **Kotlin + Jetpack Compose**
(лабораторная №3 была на Java + JavaFX; код оттуда не использовался).

## Что умеет приложение

| Вкладка | Что показывает |
|---|---|
| **Конвертер** | Перевод суммы между MDL и любой из ~40 валют НБМ, курс пары, дата курса |
| **Неделя** | График за 7 дней, минимум, максимум, среднее, изменение (абсолютное и в %), тенденция: рост / падение / без изменений |
| **Месяц** | То же за 30 дней |

- **Без интернета** приложение не падает: курсы берутся из кэша, который
  хранится в файлах и переживает перезапуск. На экране всегда видно, на какую
  дату данные и что они сохранённые.
- **Ошибки** показываются понятным текстом с кнопкой «Повторить» (нет сети,
  сайт не ответил, некорректный ответ, неверная сумма).

## Источник данных

Официальный XML НБМ, один запрос на один день:

```
https://www.bnm.md/ru/official_exchange_rates?get_xml=1&date=ДД.ММ.ГГГГ
```

История за неделю или месяц собирается из ответов за каждый рабочий день
(5 или ~22 запроса). Каждый ответ сохраняется в
`files/rates/ГГГГ-ММ-ДД.xml`. Прошлые курсы не меняются, поэтому повторно
они не скачиваются. Выходные пропускаются: в эти дни НБМ отдаёт курс пятницы.

## Структура

```
app/src/main/java/md/bnm/rates/
├── core/   чистая логика без Android: парсер XML, проверка суммы,
│           конвертация, статистика периода, рабочие дни
├── data/   загрузка с сайта НБМ, файловый кэш, репозиторий
└── ui/     экраны Compose и ViewModel
app/src/test/   unit-тесты (JUnit 4) и настоящие ответы НБМ как образцы
```

## Требования

- JDK 17 или новее (подходит JDK 23).
- Android SDK 35 (ставится из IntelliJ IDEA или Android Studio).
- IntelliJ IDEA с плагином Android или Android Studio.
- Эмулятор Android 8.0+ (API 26+) или телефон с включённой отладкой по USB.

Путь к SDK задаётся в `local.properties` (IDE создаёт этот файл сама) или в
переменной окружения `ANDROID_HOME`:

```
sdk.dir=C\:\\Users\\<имя>\\AppData\\Local\\Android\\Sdk
```

> Путь к проекту не должен содержать кириллицу и лучше не лежать в OneDrive,
> например `C:\dev\bnm-rates-android`.

## Запуск

Откройте папку проекта в IDE, дождитесь Gradle Sync, выберите эмулятор и
нажмите **Run 'app'**.

## Тесты

Одна команда из корня проекта.

Windows:
```
.\gradlew.bat test
```

macOS / Linux:
```
./gradlew test
```

Отчёт после запуска: `app/build/reports/tests/testDebugUnitTest/index.html`.

Что покрыто (64 теста):

| Класс | Что проверяется |
|---|---|
| `BnmXmlParserTest` | разбор настоящего ответа НБМ, номинал 100, пустой и битый ответ, DOCTYPE |
| `PeriodStatsTest` | min / max / среднее / изменение в %, тенденция, пустой набор данных |
| `AmountInputTest` | пустое поле, буквы, ноль и минус, три знака после запятой, слишком большая сумма |
| `ConverterTest` | EUR→MDL, кросс-курс EUR→USD, MDL→MDL, неизвестная валюта |
| `BusinessDaysTest` | выходные, даты недели и месяца |
| `FileRateCacheTest` | запись, чтение, поиск последнего сохранённого дня |
| `RateRepositoryTest` | офлайн-режим, кэш, выходные, частично загруженная история |
